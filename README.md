## AtlasImage

A native macOS menu-bar screenshot tool: capture an area, a window or the full screen, send it where you need it, and annotate, paint and save it in seven formats. Includes editor tools, paint tools, layers, numbered bullets, and editable .screenshot.json sidecars.

- Version 1.0.0, released 2026-11-20
- Requires macOS 14 or later
- Download: [DMG](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasimage/AtlasImage-1.0.0.dmg) · [zip](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasimage/AtlasImage-1.0.0.zip)
- Install: open the DMG and drag AtlasImage to Applications.

## AtlasTerm

A native macOS terminal for running many AI coding agents at once: see which session needs you, jump to it in one keystroke, and give each one its own git worktree. Plain shells also keep a searchable command log.

- Version 1.0.6, released 2026-11-18
- Requires macOS 14 or later
- Download: [DMG](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasterm/AtlasTerm-1.0.6.dmg) · [zip](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasterm/AtlasTerm-1.0.6.zip)
- Install: open the DMG and drag AtlasTerm to Applications.
