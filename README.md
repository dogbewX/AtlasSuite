## AtlasImage

A native macOS menu-bar screenshot tool: capture an area, a window or the full screen, send it where you need it, and annotate, paint and save it in seven formats. Includes editor tools, paint tools, layers, numbered bullets, and editable .screenshot.json sidecars.

- Version 1.0.3, released 2026-11-24
- Requires macOS 14 or later
- Download: [DMG](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasimage/AtlasImage-1.0.3.dmg) · [zip](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasimage/AtlasImage-1.0.3.zip)
- Install: open the DMG and drag AtlasImage to Applications.

## AtlasTerm

A native macOS terminal for running many AI coding agents at once: see which session needs you, jump to it in one keystroke, and give each one its own git worktree. Plain shells also keep a searchable command log.

- Version 1.0.11, released 2026-11-25
- Requires macOS 14 or later
- Download: [DMG](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasterm/AtlasTerm-1.0.11.dmg) · [zip](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasterm/AtlasTerm-1.0.11.zip)
- Install: open the DMG and drag AtlasTerm to Applications.

## AtlasMDV

A small native macOS viewer for Markdown files: open a .md file, read it rendered GitHub-style in light or dark mode, and export it as PDF, Word (.docx) or PowerPoint (.pptx). Can be set as the default app for Markdown files in Finder.

- Version 1.0.1, released 2026-11-23
- Requires macOS 14 or later
- Download: [DMG](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasmdv/AtlasMDV-1.0.1.dmg) · [zip](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlasmdv/AtlasMDV-1.0.1.zip)
- Install: open the DMG and drag AtlasMDV to Applications.

## AtlasText

A native macOS scratchpad and code-snippet editor: every tab is saved within a second and restored after any restart or crash, with no Save command. Includes syntax highlighting for more than 25 languages, Markdown preview, notebooks, global full-text search, external file editing, export, and an optional AI assistant that stays off until you turn it on.

- Version 1.0.0, released 2026-11-27
- Requires macOS 14 or later
- Download: [DMG](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlastext/AtlasText-1.0.0.dmg) · [zip](https://github.com/dogbewX/AtlasSuite/raw/main/downloads/atlastext/AtlasText-1.0.0.zip)
- Install: open the DMG and drag AtlasText to Applications.
